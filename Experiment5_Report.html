Task 14–15 — First-order DPCM predictor, PCM vs DPCM

Expected before running: because a sine wave is highly correlated sample-to-sample, predicting each sample from the previous reconstructed sample should leave a much smaller residual than the signal itself. Quantizing that residual (DPCM) should therefore give a noticeably lower MSE than quantizing the raw signal directly (PCM) at the same bit budget.
Observation vs theory: MSE(PCM) ≈ 1.18×10⁻³ vs MSE(DPCM) ≈ 2.44×10⁻⁴ — roughly a 4.8× reduction, agreeing with theory: DPCM's gain over PCM equals the prediction gain, i.e. the ratio of the signal variance to the residual variance. The residual e[n] is visibly smaller and flatter than x[n] except at the sine's peaks/troughs, where the first-order predictor lags most (curvature is highest there, and a first-order predictor only extrapolates linearly) — the small bumps in e[n] at each extremum are exactly this lag, not a bug.

Task 16–17 — Delta modulation: step size × input speed

Expected before running: for the slowly varying input, a small Δ should track the signal well and error should be dominated by granular noise (small ± oscillation around a well-tracked curve), growing steadily as Δ increases. For the rapidly varying input, Δ has to satisfy Δ·Fs ≥ max|dx/dt| just to keep up; since the fast signal's slope requirement (~11.7×10³) is far above every tested Δ (≤0.45 → Δ·Fs ≤ 3600), the fast case should show slope overload at every step size, with MSE actually falling as Δ grows because a bigger step chases the steep slope better (even though it makes flat regions grainier).
Observation vs theory: confirmed. Slow input: MSE rises monotonically with Δ (8.3×10⁻⁴ → 7.2×10⁻³ → 6.7×10⁻²) and the staircase visibly hugs the sine, with the only artifact being the expected small ripple (granular noise). Fast input: MSE falls with increasing Δ (0.391 → 0.363 → 0.246) and the staircase visibly cannot keep pace with the signal at any Δ tested — classic slope overload, where the output is a diagonal ramp that lags the true waveform. No discrepancy from theory was found; the diagnostic test used was inspecting whether the local staircase slope Δ·Fs exceeds the local signal slope dx/dt — where it doesn't, overload appears.

MSE vs step size (required visualization)

Expected before running: the classic U-shaped curve for a signal that spends most of its Δ-range in the trackable regime (slow input): MSE should fall as Δ approaches the minimum non-overload step, then rise again as granular noise takes over. The fast input, whose slope requirement is never met in this sweep, should look monotonically decreasing instead of U-shaped.
Observation vs theory: matches exactly. The slow-input curve has a sharp minimum at Δ ≈ 0.027 — matching the analytically predicted overload threshold Δ_min = max|dx/dt| / Fs = (0.85·2π·40)/8000 ≈ 0.0267 almost exactly — with slope overload to its left and granular noise dominating to its right. The fast-input curve keeps falling across the whole swept range because its own threshold (≈1.47) lies far outside it, so it never enters the granular-noise-dominated regime here.

Task 18 (optional) — Adaptive delta modulation

Expected before running: letting Δ grow on consecutive same-sign bits (slope overload → bigger steps needed) and shrink on alternating bits (flat regions → smaller steps wanted) should let one adaptive modulator handle both regimes better than any single fixed Δ, at the cost of extra side information (the receiver must track the same adaptation rule).
Observation vs theory: the adaptive step size climbs from 0.05 toward the 0.45 cap within about six samples of sustained same-sign error and tracks the fast sine's steep flanks visibly better than the fixed small step, cutting MSE from 0.391 to 0.349 (≈11% lower) on the same signal. This agrees with the expected effect; the residual overload is because even the 0.45 ceiling used here is still below the fast signal's true slope requirement (~1.47), so some overload remains by design of the parameter choice, not an error in the adaptation logic.
